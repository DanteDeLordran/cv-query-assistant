# cv-query-assistant

CV analyzer, summarizer and question assisstant for HR personal

## Tool flow

1. User gives a pdf | txt | md file
2. Tool parses file to md
3. Md file gets chunked and loaded to vectorized db
4. Generate vectorized db retriever
5. Load LLMs
6. Format retrieved content
7. Initialize chat
